既然在網路（Network）資安監控中有 **Zeek**（深度的流量與中繼資料分析）和 **Suricata**（強大的入侵偵測/防禦系統 IDS/IPS）這兩大神器，那麼在端點（Endpoint）的可視性與監控上，自然也有相對應的重量級工具。

端點監控主要關注的是主機（伺服器、工作站）內部的行為，例如：**進程（Process）建立了什麼、修改了哪些檔案、連向了哪個 IP、或者登錄表（Registry）被怎麼改動**。

以下是目前業界最主流、常與 Zeek/Suricata 搭配使用的開源及免費端點可視性（Endpoint Visibility）與 EDR 工具：

---

## 1. 系統狀態「資料庫化」：Osquery

如果 Zeek 是把網路流量變成結構化的日誌，那 **Osquery** 就是把「作業系統」變成一個可以用 SQL 查詢的資料庫。

* **核心概念：** 它將作業系統的狀態（如執行中的進程、載入的核心模組、開放的網路連接埠、硬體資訊）抽象化為一條條的 SQL 表格。
* **怎麼用：** 你可以直接用 `SELECT * FROM processes WHERE on_disk = 0;` 來查詢有沒有只在記憶體中執行的可疑進程。
* **適用場景：** 定期資產盤點、合規性檢查、主機狀態快照。通常會搭配 FleetDM 或 Kolide 進行大規模集中管理。

## 2. 全方位開源 EDR/XDR：Wazuh

**Wazuh** 是目前最受歡迎的開源主機入侵偵測（HIDS）與 EDR 系統（基於早期的 OSSEC 發展而來）。

* **核心概念：** 在端點部署 Agent，收集日誌並與後端的規則庫（Ruleset）進行即時比對。
* **強大功能：** * **FIM（檔案完整性監控）：** 檔案被竄改立刻報警。
* **漏洞檢測：** 自動掃描主機上裝了哪些有安全漏洞的軟體。
* **惡意軟體偵測：** 與 VirusTotal 整合，自動對可疑檔案進行檢驗。
* **主動回應（Active Response）：** 發現攻擊時自動封鎖 IP 或隔離阻斷進程。



## 3. Windows 防守方標配：Sysmon (System Monitor)

雖然微軟的 Windows 有內建的事件檢視器（Event Viewer），但預設的日誌對於資安分析來說不夠詳細。Sysmon 是微軟 Sysinternals 工具包中的免費神物。

* **核心概念：** 它是個系統服務與驅動程式，一經安裝，就會把 Windows 的底層行為轉化為極度詳細的資安日誌（如 Event ID 1: 進程建立、Event ID 3: 網路連線）。
* **怎麼用：** 它本身不帶分析介面，通常會搭配 **SwiftOnSecurity** 的設定檔，並透過 Winlogbeat 或 Elastic Agent 將日誌送往 SIEM（如 ELK、Splunk）進行分析。
* **優勢：** 幾乎所有企業的 Windows 威脅獵捕（Threat Hunting）都離不開它。

## 4. 數位鑑識與威脅獵捕利器：Velociraptor

如果你需要的是像網路鑑識那樣，在事件發生時**深入主機進行調查與證據採集（DFIR）**，那 Velociraptor 是首選。

* **核心概念：** 它使用一種叫 VQL（Velociraptor Query Language）的強大查詢語言，可以非常快速地在數萬台端點上同時進行威脅搜捕（Hunting）。
* **強大功能：** 可以直接遠端拉取主機的 MFT（主檔案表）、記憶體、瀏覽器歷史紀錄，甚至直接隔離受駭主機。

## 5. Linux 核心級監控：Auditd & eBPF 工具 (如 Tetragon)

如果是針對 Linux 伺服器：

* **Auditd：** Linux 核心內建的稽核系統，可以監控所有系統呼叫（Syscall），例如誰讀取了敏感檔案、誰執行了管理員權限。
* **eBPF 技術（如 Cilium Tetragon）：** 近年最火熱的技術，不用修改核心就能在作業系統核心層（Kernel）提供安全監控，效能極高，非常適合 Kubernetes 和雲端原生環境。

### 工具快速對比表

| 工具名稱 | 主要定位 | 適合作業系統 | 核心特色 |
| --- | --- | --- | --- |
| **Osquery** | 端點狀態查詢/稽核 | Windows, Linux, macOS | 用 SQL 語法查系統狀態，像查資料庫一樣簡單 |
| **Wazuh** | 開源 EDR / HIDS | Windows, Linux, macOS | 功能最全面，含防禦、漏洞偵測與日誌分析 |
| **Sysmon** | Windows 行為深度記錄 | Windows (Linux 有簡化版) | 微軟官方出品，進程與網路行為軌跡記錄首選 |
| **Velociraptor** | 數位鑑識與事件回應 (DFIR) | Windows, Linux, macOS | 威脅獵捕反應極快，適合資安應變小組 (IR) |
| **Tetragon (eBPF)** | 雲原生/核心級監控 | Linux | 效能極高，專注在容器與 Linux 核心行為 |

通常在建構資安 SOC（資安維運中心）時，大家會用 **Zeek + Suricata** 看管網路邊界，並在內網主機裝上 **Wazuh 或 Sysmon/Osquery**，兩者日誌統一匯入 ELK 或 OpenSearch 進行關聯分析，這就是標準的開源資安防禦架構。

我們來把這幾個工具的定位梳理清楚，同時幫你把那兩個有點記錯的鑑識工具名稱校正回來：

---

## 1. 網路監控大套餐與大腦：Malcolm & Splunk

這兩個工具不直接產生流量，而是負責**整合、分析與呈現**。

### Malcolm：CISA 官方打包的開源網路資安「懶人包」

* **定位：** 一體化網路流量分析平台（All-in-One NSM Suite）。
* **它是什麼：** 由美國國土安全部 CISA 核心開發的開源專案。Malcolm 本身不是一個單一工具，它是一個用 Docker 包裝好的**超級套餐**。
* **裡面裝了什麼：** 它把我們前面聊到的 **Zeek**（流量分析）和 **Suricata**（IDS）裝在一起，再加上 **Arkime**（負責全封包錄製/PCAP 檢索）以及 **OpenSearch/Logstash**（負責做漂亮的儀表板）。
* **角色：** 如果你不想花好幾天手動把 Zeek、Suricata、資料庫串起來，直接部署 Malcolm，它就幫你把所有的網路日誌和封包分析介面通通打包做好了。

### Splunk：資安維運的「終極大腦」 (SIEM)

* **定位：** 商業級的大數據日誌分析與安全資訊事件管理平台（SIEM）。
* **它是什麼：** 資安界的超級豪車（功能極強，但也非常貴）。它自己不收集流量或端點資料，而是像個黑洞一樣，**把所有地方的日誌全部吸進來**。
* **角色：** 你的 Zeek 日誌、Suricata 警報、Sysmon 端點行為、甚至防火牆和雲端（AWS/Azure）日誌，通通丟進 Splunk。它透過強大的 SPL 語法進行「跨來源關聯分析」。例如：當 Suricata 發現外部攻擊（網路），Splunk 能立刻幫你查 Sysmon（端點）確認那台主機有沒有真的長出惡意進程，幫分析師抓出完整的攻擊故事線。

---

## 2. 數位鑑識雙雄：硬碟與記憶體的深度調查

當主機被入侵了，你要保留證據上法院，或者是想深入調查黑客留下了什麼，這時就要動用「數位鑑識（DFIR）」工具。

### 「spy什麼」 ➡️ 其實是 Autopsy (歐塔普西)

* **定位：** 開源數位鑑識平台（**硬碟與檔案系統鑑識 / 死機鑑識**）。
* **名字由來：** 英文的 Autopsy 是「屍體解剖」的意思（發音聽起來像 Auto-psy，常被誤記為 spy）。在資安上，就是對受駭主機的「硬碟鏡像（Disk Image）」進行死後解剖。
* **它是什麼：** 它是經典開源鑑識工具 The Sleuth Kit (TSK) 的圖形化介面（GUI），是鑑識人員（包含執法單位）的標配。
* **角色：** 當你把受駭電腦的硬碟複製一份檔案（避免破壞現場）丟進 Autopsy，它可以幫你：
* **回復被黑客刪除的惡意檔案。**
* **挖出這台電腦插過哪些 USB（查看登錄表軌跡）。**
* **分析瀏覽器歷史紀錄、下載圖表，排出事件發生的時間軸（Timeline）。**



### 「volitate」 ➡️ 正確名稱是 Volatility Framework

* **定位：** 全球最頂尖的開源**記憶體鑑識工具（Memory Forensics / 活機鑑識）**。
* **它是什麼：** 黑客現在很聰明，很多惡意軟體採用「無檔案（Fileless）」攻擊，它們只活在電腦的 **RAM（隨機存取記憶體）** 裡面，電腦一關機或看硬碟根本找不到。Volatility 就是專門用來解剖「記憶體傾印檔案（RAM Dump）」的工具。
* **角色：** 當受駭主機還開著時，分析師把 RAM 的內容全部倒出來成一個檔案，然後用 Volatility 去解析：
* **提取記憶體中正在執行的隱藏進程。**
* **找出當時正在連線的網絡 Socket。**
* **甚至直接從記憶體中撈出黑客剛剛輸入的密碼或緩衝區裡的惡意代碼（Code Injection）。**



---

## 總結：這些工具在資安防禦圖中的位置

如果用一個防範犯罪的場景來比喻：

| 領域 | 工具 | 角色比喻 |
| --- | --- | --- |
| **網路監控** | Zeek / Suricata | 門口的監視器與紅外線報警器 |
| **端點監控** | Sysmon / Wazuh | 房間內的動態感應器、清點保險箱狀態 |
| **數據整合** | **Malcolm / Splunk** | **中控室的警衛大螢幕與歷史紀錄搜尋系統** |
| **硬碟鑑識** | **Autopsy (spy...)** | **事後法醫來到現場，採集指紋、翻找抽屜與垃圾桶（鑑識硬碟）** |
| **記憶體鑑識** | **Volatility (volitate)** | **定格案發當下的時間，抽血檢查體內殘留的毒素與短暫記憶（鑑識 RAM）** |

在業界標準的資安事件回應（Incident Response）流程中，日常看 **Splunk/Malcolm** 告警，出事了就用 **Wazuh/Sysmon** 做初步圍堵，最後把主機拉下來用 **Autopsy** 和 **Volatility** 做翻天覆地的徹底鑑識。
