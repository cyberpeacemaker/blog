Whether you can invite others to an event depends on the settings configured by the event organizer. Generally, if the "Guests can modify event" or "Invite others" setting is enabled, you will be able to add more people.

You can check if you have the permission and try to invite others by following these steps:

- **Use the Edit icon:** In the top-right corner of the event details view (as seen in your image), there is a **pencil icon**. Clicking this may allow you to edit event details, including adding guests to the invite list.
    
- **Look for an "Add guests" field:** If you enter the edit mode, look for an "Add guests" field where you can input the email addresses of the people you wish to invite.
