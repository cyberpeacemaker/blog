您指的可能是職場或商務英文中常混用的 **"push back"**、**"back and forth"** 或 **"push and pull"**。

在職場溝通中，大家常說的「來回 push back」，通常是由以下幾個常見說法組合或延伸而來的：

## 1. Push back (提出異議 / 推回需求)

當對方（如客戶、主管或跨部門團隊）提出不合理的要求、時程或預算時，你**提出反駁、拒絕或爭取調整**。

We need to push back on this deadline because it's unrealistic.

- **補充說明**：也可以當作名詞使用（寫成 `pushback`），代表「阻力」或「反對意見」（例如：_We received some pushback from the product team._）。
    

## 2. Go back and forth (來回溝通 / 來回修改)

強調雙方為了達成共識或釐清細節，**來回討論、修改或發郵件了多次**。

After a lot of back and forth, we finally reached an agreement.

## 3. Push and pull (互相拉扯 / 角力)

形容雙方在談判或合作時，彼此施壓與妥協的**角力過程**。

There is always a lot of push and pull during contract negotiations.

### 核心差異與情境建議

- **Push back**：重點在於「拒絕 / 推回對方的要求」。
    
- **Back and forth**：重點在於「來回多次溝通」。
    
- **職場常見混用語「來回 push back」**：指的就是「雙方針對需求或細節，來回提出了好幾次異議與拉鋸」。
