How you share a GitHub repository depends on whether it is **public** (anyone can see it) or **private** (only invited people can see it).

Here are the easiest ways to do both.

## Scenario 1: Sharing a Private Repo (or giving edit access)

If your repository is private, or if you want to allow someone else to push code and make changes, you need to add them as a **collaborator**.

1. Go to your repository on GitHub.
    
2. Click on the **Settings** tab (the gear icon at the top right of the repo menu).
    
3. In the left sidebar, under the _Access_ section, click **Collaborators**.
    
4. Click the green **Add people** button.
    
5. Type the person's **GitHub username**, **full name**, or **email address** into the search bar.
    
6. Select them from the dropdown list, choose their permission level (usually _Write_ or _Admin_), and click **Add [username] to this repository**.
    

> 💡 **Note:** GitHub will send an email invitation to the user. They must accept the invitation before they can access the repository. You can copy the invite link from the same page and send it to them directly if they miss the email.

## Scenario 2: Sharing a Public Repo

If your repository is public, anyone on the internet can see it. You don't need to grant special access unless you want them to edit it.

- **Just share the URL:** Copy the link from your browser's address bar (e.g., `[https://github.com/your-username/your-repo-name](https://github.com/your-username/your-repo-name)`) and send it via Slack, email, or text.
    
- **For cloning:** They can click the green **Code** button on your repository page to copy the HTTPS or SSH link to clone it to their local machine.
    

## Quick Tip: Organizations vs. Personal Accounts

If you are working on a team project, consider creating a free **GitHub Organization**. This allows you to manage multiple repositories and group users into **Teams** (like "Frontend" or "Designers"), making it much easier to manage access for large groups of people all at once.

---

Once you accept a repository invitation, it **will not** automatically show up under the "Repositories" tab on your public profile page because you aren't the owner.

Instead, you can find and access it in these locations:

### 1. The GitHub Home Dashboard (Easiest Way)

Go to the main GitHub home page at [github.com](https://github.com/) (make sure you are logged in).

- Look at the **left sidebar** under the **Repositories** section.
    
- It shows a list of all your recent repos, including ones where you are a collaborator. You can use the search bar right above that list to type the repo's name if it doesn't show up immediately.
    

### 2. Your Account Settings (The Master List)

If you want to see a clean list of every single repository you’ve been added to, go here:

- Direct Link: [github.com/settings/repositories](https://github.com/settings/repositories)
    
- Alternatively, click your **profile picture** in the top right corner → click **Settings** → click **Repositories** in the left sidebar. This page lists your owned repos and explicitly shows a section for repositories you collaborate on.
    

### 3. The Global Search Bar

Since you now have access, you can simply type the name of the repository into the **Search bar** at the very top of any GitHub page. It will appear in the dropdown results.

### 💡 Quick Tip: How to show it on your profile

If you want this shared repository to be visible to people visiting your GitHub profile, you can **Pin** it:

1. Go to your main GitHub profile page.
    
2. Scroll down to the **Pinned** section and click **Customize your pins** (top right of that section).
    
3. Change the filter from "Your repositories" to **"Repositories you contribute to"**.
    
4. Check the box next to the repo and click **Save pins**.
