重灌（重新安裝）作業系統通常能清除大部分的軟體層級惡意程式，但現代的高級持續性威脅（APT）已經演變出多種手段，能夠在硬碟被格式化後依然「存活」。

以下是目前常見導致重灌後仍持續受駭（Persistent Compromise）的主要手法：

---

## 1. 韌體級植入（Firmware Implants）

這是最難纏的手法。惡意程式不儲存在硬碟中，而是藏在主機板或其他硬體組件的晶片裡。

* **UEFI/BIOS Malware:** 惡意程式植入主機板的 UEFI 韌體中。由於 UEFI 在作業系統載入前就執行，它可以在新系統安裝過程中，重新將惡意程式注入到新的系統核心中。
* *著名案例：LoJax, CosmicStrand, MoonBounce。*


* **硬碟控制器韌體（HDD/SSD Firmware）:** 攻擊者修改硬碟控制晶片的韌體。即使你格式化了儲存分區，控制晶片本身仍受控，可以隨時隱藏惡意資料或在讀寫時篡改系統檔。

---

## 2. 硬體與週邊設備攻擊

利用電腦中具有獨立處理能力的組件。

* **惡意週邊裝置（BadUSB / DMA Attack）:**
* **BadUSB:** USB 裝置（如滑鼠、隨身碟）內建微控制器，偽裝成鍵盤輸入惡意指令。
* **DMA 攻擊:** 利用 Thunderbolt 或 PCIe 介面的「直接記憶體存取（DMA）」功能，繞過 CPU 直接讀寫記憶體，在重灌後透過這些介面重新感染。


* **網卡或顯卡韌體:** 這些週邊有自己的處理器和記憶體，亦可被用作藏匿惡意程式的避風港。

---

## 3. 雲端與帳戶同步（Credential/Profile Persistence）

這屬於「邏輯層面」的持續受駭，而非技術層面的漏洞。

* **瀏覽器與雲端同步:** 現代人習慣登入 Chrome 或 Edge 帳號。如果你原本的瀏覽器擴充功能（Extensions）或書籤包含惡意指令，重灌後只要一登入帳號，惡意擴充功能就會自動下載回來。
* **作業系統設定同步:** Windows 的 OneDrive 或帳號同步功能，可能會將先前被篡改過的設定、腳本或排程工作（Scheduled Tasks）重新下載回新電腦。

---

## 4. 供應鏈與安裝媒體感染

如果你的「乾淨來源」本身就是髒的，重灌也沒有意義。

* **被篡改的 ISO 鏡像:** 許多人下載非官方、已啟用的「精簡版」或「優化版」Windows。這些鏡像檔在封裝時就可能預埋了後門。
* **受感染的 USB 製作工具:** 用來製作開機隨身碟的工具若被感染，它會在製作過程中將惡意代碼植入隨身碟。

---

## 5. 路由器與網路設備感染（Network-Level Compromise）

有時候被駭的不是電腦，而是網路環境。

* **DNS 劫持:** 攻擊者入侵了你的路由器（Router），修改了 DNS 設定。重灌後的電腦只要連上網，下載驅動程式或軟體時，可能會被導向惡意伺服器，下載到被掉包的安裝檔。
* **中間人攻擊（MITM）:** 攻擊者在區域網路中攔截流量，利用未加密的更新通道重新注入惡意程式。

---

## 如何防範重灌後的持續受駭？

若懷疑遭遇的是這類高級威脅，單純重灌是不夠的，建議採取以下步驟：

1. **更新並鎖定 UEFI:** 刷新主機板韌體（BIOS Flash），並開啟 **Secure Boot**（安全啟動）。
2. **硬體清零:** 如果懷疑是硬碟韌體層級，物理更換一顆全新的硬碟。
3. **使用官方來源:** 僅從 Microsoft 官網下載 Media Creation Tool 製作安裝碟。
4. **重設網路設備:** 將路由器恢復原廠設定，更新韌體，並更換管理員密碼。
5. **斷網安裝:** 在新系統安裝完畢並開啟防火牆前，先不要連接網路。
