# ETA JA4 JA4L Session Resumption
哈哈，既然你都叫我一聲「師傅」了，那我今天就把壓箱底的**現代 ETA 終極絕活**全掏出來給你！

前面我們聊了統計學（馬可夫鏈、HMM）和基礎特徵，但威脅獵人的世界變化極快。攻擊者為了躲避傳統的 JA3 指紋，開始大量使用「指紋隨機化（Fingerprint Randomization）」；而為了躲避監控，甚至會利用加密通道的機制來隱藏自己。

為了應對這些，業界在 2024 到 2026 年迎來了技術大洗牌。以下是目前最前沿、能讓你在藍隊（Blue Team）橫著走的 **3 個終極 ETA 獵捕技術與範例**：

## 技術一：終極指紋革命 —— JA4+ 家族（打敗隨機化的利器）

你可能聽過 JA3，但實務上 JA3 已經快被淘汰了，因為它極易被攻擊者隨機化干擾。現代頂尖獵人使用的是由 John Althouse 開發的 **JA4+ 家族**。

JA4+ 最強大的地方在於，它將指紋拆成了可讀性極高、以底線區隔的 **`a_b_c` 三段式結構**。

```
[JA4 指紋範例]  t13d2013_02713d6af862_c104928e4612
                 └── a ──┘ └────── b ──────┘ └────── c ──────┘
```

- **`a` 段（傳輸與版本）：** 協定類型（TCP/QUIC）、TLS 版本、SNI 是否存在、ALPN 等（例如 `t13d` 代表 TCP、TLS 1.3、有 SNI）。

- **`b` 段（演算法雜湊）：** 客戶端支援的密碼學套件（Cipher Suites）排序雜湊。

- **`c` 段（擴充功能與簽章）：** 擴充欄位（Extensions）與簽章演算法的排序雜湊。


### 獵人如何用 JA4+ 破譯「指紋隨機化」？

有些狡猾的 C2 惡意程式（如某些高階 APT 腳本）在每次發起連線時，會**故意隨機排列密碼套件**。這會導致舊型的 JA3 雜湊值每次都完全不同，讓自動化防火牆形同虛設。

- **JA4 破解法（拼圖聯防）：**

    當攻擊者隨機化密碼套件時，只有 `b` 段會改變，但它的 `a` 段（作業系統網路堆疊特徵）與 `c` 段（支援的擴充功能，通常由編譯器或底層 SSL 庫決定）依然保持不變！

    > **獵人語法：** 我們可以只針對 `JA4_ac`（即捨棄 `b` 段，只比對 `a` 與 `c`）進行關聯分析。如果發現內網出現大量 IP 不同、JA3 不同，但 **`JA4_ac` 卻完全一致** 的連線，就能瞬間抓出這隻正在玩「變臉」的惡意程式！


## 技術二：空間幾何的物理學魔法 —— JA4L (延遲與距離指紋)

這是一個會讓你驚嘆「這也可以？！」的技術。**JA4L (Latency Fingerprinting)** 透過測量 TCP 握手與 TLS 協商微秒級的時間差，不看 IP，直接用物理學（光速）計算出客戶端與伺服器之間的「物理距離」！

在光纖中，光速傳播的速度是固定的。我們可以透過計算 RTT（往返時間）來估算兩點之間的理論物理距離：

$$D = \frac{j \cdot c}{p}$$

- $D$：理論物理距離（公里）。

- $j$：JA4L 所測量到的微秒級傳播延遲（Propagation Delay）。

- $c$：光在光纖中的速度（約 $0.206 \text{ km/}\mu\text{s}$）。

- $p$：網路傳播修正係數（通常在 $1.5 \sim 2.0$ 之間，取決於地形與路由複雜度）。


```
[企業內網主機] ──────────────────────── (經過無數路由與海底光纜) ────────────────────────> [目標伺服器]
               <─── 實測 TCP/TLS 延遲 148ms ───> 物理距離推估：約 15,000 公里 (跨洋連線)
```

### 獵捕情境：抓出「內網間諜」與「地理位置偽裝」

1. **情境：** 攻擊者入侵了企業內網，為了掩人耳目，他們使用 VPN 或 Tor 節點，將 C2 伺服器偽裝成「位於台灣本地的合法 CDN 節點」（Geo-IP 顯示為台灣 IP）。

2. **獵人運用 JA4L：**

    我們觀察這個看似連往台灣本地 IP 的加密連線，但實測其 **JA4L 算出來的物理距離高達 10,000 公里以上**（這代表封包實際上繞了半個地球，經過了海外的 Proxy/Tor 節點才連到該 IP）。

    > **結論：** 物理規律無法被軟體偽裝。只要 IP 位置與 JA4L 計算出的物理距離嚴重不符，就代表這是一個**地理位置造假、背後隱藏著 VPN/代理隧道的惡意連線**。


## 技術三：無聲的逃逸術 —— 獵捕 TLS 會話恢復 (Session Resumption) 濫用

這是許多高級威脅（APT）最喜歡用來「致盲」安全設備的手段，但也是獵人絕佳的切入點。

為了加速連線，TLS 支援「會話恢復」機制。當客戶端第二次連線同一個伺服器時，可以使用之前的 **Session ID** 或 **Session Ticket** 直接重用加密金鑰，**跳過完整的 TLS 握手**（不會發送完整的 Client Hello）。

```
[第一次連線] Client Hello (明文，可被 JA3/JA4 記錄) ───> 建立加密
[第二次連線] Session Ticket (直接恢復) ───> 建立加密 (無 Client Hello，安全設備致盲)
```

### 攻擊者的詭計：

因為沒有完整的 Client Hello，內網的 Zeek、IDS 等安全設備就**無法提取 JA3/JA4 指紋**。攻擊者會故意在第一次連線時偽裝成普通瀏覽器，隨後利用 Session Resumption 保持極長期的惡意 C2 通訊，讓安全設備在後續的幾天甚至幾週內，完全失去對其指紋的監控能力。

### 獵人的破解之道（獵捕 Session 異常）：

1. **異常 Session ID 噴灑（Session Spraying）：**

    攻擊者有時會盜用其他合法主機的 Session Ticket 來嘗試與 C2 建立連線。如果我們在日誌中看到：**「某個 Session ID 被多台不同的內部 IP 主機拿來進行連線恢復」**，這就是極其嚴重的 Session Hijacking（會話劫持）或 C2 憑證共享行為。

2. **無歷史記錄的會話恢復（Orphaned Resumption）：**

    在正常的網路行為中，會話恢復前，必定能在幾小時內找到同一個 IP 對同一個目的地的「完整 TLS 握手歷史記錄」。

    > **獵人聯防語法：**
    >
    > 篩選出所有「嘗試進行 TLS Session Resumption，但在過去 24 小時內，該來源與目標 IP 之間**沒有任何完整 TLS 握手日誌**」的連線。這通常代表攻擊者正在使用預先寫死、硬編碼（Hardcoded）在惡意程式裡的 Session 資訊進行隱蔽通訊。


## 師傅的威脅獵人金句

> 「攻擊者能修改軟體程式碼、能隨機化封包，但他們無法修改**網路拓撲的物理距離**，也無法規避**協定設計的邏輯缺陷**。」

這就是為什麼 ETA 如此迷人。它不只是在看一堆冷冰冰的 Hex 碼或 IP 地址，而是透過**物理學、密碼學協定邏輯、以及統計學**，在加密的迷霧中進行一場精準的「盲眼推理」。

我們今天分享了 **JA4+ 的多維指紋聯防**、**JA4L 的光速距離推估**，以及 **Session Resumption 的協定漏洞獵捕**。
