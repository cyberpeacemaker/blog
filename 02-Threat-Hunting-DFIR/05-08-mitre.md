## 🛑 一、 企業現實與挑戰

目前多數企業在面對入侵時，往往處於「治標不治本」的狀態：

* **偵測盲點：** 雖有告警，但無法追蹤攻擊進入點（Initial Access）。
* **處置侷限：** 僅能採取「下線、清除、公告」三部曲，缺乏深度的根因分析。
* **持續威脅：** 內網中可能仍留有大量具備後門（Backdoor）的隱蔽裝置。

## ⚔️ 二、 攻擊戰術與技術 (TTPs)

### 1. 惡意軟體與持久化技術

* **RAT (遠端存取木馬):** 具備側錄、截圖、視窗追蹤、影音存取等全面監控功能。
* **隱匿技術:**
    * **Rootkit:** 修改 API 呼叫，偽造系統資訊以隱藏檔案、連線與進程。
    * **Bootkit:** 感染 MBR（主開機紀錄），在作業系統啟動前獲取控制權。
    * **Time Stomping:** 更改檔案時間戳記，規避鑑識檢查。


* **分階段部署:** 先利用輕量級惡意軟體進行掃描（收集物聯位置、進程清單），確認目標價值後才部署進階 Payload。

### 2. 入侵途徑與橫向移動

* **社交工程:** 魚叉式釣魚（獲取憑證）、水坑攻擊（結合 BeEF 框架進行瀏覽器偵查與指紋識別）。
* **內網滲透:** 利用預設開啟的 **NetBIOS**（配合 Responder 工具）或 **UAC 繞過**獲取權限。
* **離線系統跳板 (Air-gapped):** 利用 **Xagent** 感染 USB 驅動器，在不連網的系統間建立偽網路傳輸資料。

### 3. C2 通訊與執行

* **隱蔽通訊:** 惡意程式會利用系統 Proxy、注入瀏覽器連線，甚至盜用 VPN 憑證來建立 C2 隧道。
* **代碼注入:** 透過 `NSTask`、`rundll32.exe` 或 **APC 注入**等方式執行。

## 📐 三、 防禦模型與分析框架

| 模型名稱 | 核心用途 |
| --- | --- |
| **MITRE ATT&CK** | 攻擊者行為百科全書，將攻擊拆解為戰術與技術。 |
| **Cyber Kill Chain** | 描述攻擊者的連鎖階段（從偵查到行動目標）。 |
| **STRIDE** | 威脅建模工具，用於評估系統安全性。 |
| **Pyramid of Pain** | 定義偵測指標（IoC）的難易度，目標是提高攻擊者的成本。 |
| **MITRE Shield** | 強調**主動防禦**與反制（如誘餌、阻斷）。 |

## 🛠️ 四、 資安工具箱與專案

### 1. 偵測與監控

* **Sysmon:** 微軟官方提供的強化版系統日誌，可深度紀錄進程、連線與驅動載入。
* **Cobalt Strike:** 強大的紅隊測試工具，其 **Beacon** 常利用處理程序注入（如注入 `rundll32.exe`）與具名管線（Named Pipes）獲取高權限。

### 2. 威脅獵捕與情報共享 (CTI)

* **情報格式:** **Sigma** (通用偵測規則標準)、**MISP** (惡意軟體情報共享平台)。
* **開源專案:**
    * **Atomic Red Team:** 模擬攻擊技術的測試腳本。
    * **HELK / ThreatHunter Playbook:** 提供完整的獵捕場景與數據分析架構。
    * **DeTT&CT:** 用於評估組織對 ATT&CK 框架的涵蓋能力。
