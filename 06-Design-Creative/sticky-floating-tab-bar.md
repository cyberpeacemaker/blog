## 1. What to Call the Component in Your Screenshot

In your screenshots, the top navigation consists of pill-shaped buttons floating over content to toggle between different views (`TA 報告`, `SIEMENS 解答`, `DELTA 解答`).

### Core Terms

- **Sticky Floating Tab Bar** (or **Floating Pill Navigation**): Describes the visual design—rounded "pill" buttons contained in a floating container stuck to the top.
    
- **Segmented Control**: The technical UI design term for a row of connected or grouped buttons used to switch between mutually exclusive views/panels on the same page.
    
- **Top Bar / Navigation Bar with Sub-view Tabs**: Describes the functional layout if it acts as the primary layout switcher.
    

### Descriptive Keywords for Prompting

- **Position/Style:** `Floating`, `Sticky / Fixed top`, `Centered`, `Pill-shaped buttons`, `Glassmorphism / Shadow outline`.
    
- **Function:** `Segmented Control`, `Tab switcher`, `View toggler`.
