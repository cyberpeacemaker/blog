## "Stories" and "Epics" in Tech

If you've been hanging around software developers or product managers, you’ve stumbled straight into the world of **Agile project management**.

First, a quick, friendly clarification: the word you heard as "epoc" is actually **Epic** (though "epoch" _is_ a tech term used for computer timestamps, in this context, it's definitely an Epic!).

Here is what these terms mean and how they work together to build software.

### 1. What is a "Story"? (User Story)

In tech, a **Story** (short for "User Story") is a very short, simple explanation of a software feature written from the perspective of the person using it. It’s the smallest unit of work that can actually deliver value to a user.

Instead of writing a dry, 50-page technical document, teams write Stories. They almost always follow this simple, human-centric template:

> **"As a** [type of user], **I want to** [do something], **so that** [I get this benefit].**"**

- **Example:** _"As a shopper, I want to filter search results by price, so that I can find items within my budget."_
    

### 2. What is an "Epic"?

An **Epic** is just a really, really big User Story. It represents a large feature or goal that is too massive to be completed all at once.

Because an Epic is too big for a developer to build in a week or two, the team breaks it down into several smaller, bite-sized **Stories**.

### How They Fit Together (An Analogy)

Think of building a product like planning a major vacation:

- **The Epic (The Big Goal):** _"Plan a trip to Japan."_ (This is too big to do in one afternoon).
    
- **The Stories (The Bite-Sized Steps):**
    
    - _"As a traveler, I want to book my flights to Tokyo..."_
        
    - _"As a traveler, I want to reserve a hotel in Kyoto..."_
        
    - _"As a traveler, I want to buy a train pass..."_
        

In a software company, developers will grab one "Story" at a time, write the code for it, and check it off the list. Once all the individual Stories under an Epic are finished, the Epic is complete!
