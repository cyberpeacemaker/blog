硬體箱接線說明

硬體箱的 Siemens 與 Delta 設備接線方式，以及 Switch 開關位置。

Switch 開關位置

  • 開關位於右邊藍色區域。

1. 西門子 (Siemens) 設備接線

  • 第一孔 (Port 1)： 連接外部網路。
  • 第二孔 (Port 2)： 插上一條網路線，直接連接到你自己的實體筆電。

2. 台達 (Delta) 設備接線

  • Port 1 (上方孔)： 連接安裝有 Ubuntu 的電腦。
  • Port 2 (下方孔)： 連接外部網路。

虛擬機啟動與網路設定操作指南

本指南包含虛擬機環境初始化、本機靜態 IP 配置、連線測試與 SSH 登入，以及事後的網路還原步驟。

認證資訊清單

項目值
Linux 主機管理密碼user@1234
虛擬機 (.32) SSH 帳號ubuntu
虛擬機 (.32) SSH 密碼ubuntu

網路架構總覽

角色IP
Linux 主機（執行 Vagrant）192.168.1.33
虛擬機（跑在主機上，SSH 目標）192.168.1.32
本機筆電（Windows）192.168.1.55

第一階段：開啟虛擬機 (Linux 主機)

請依序執行以下指令來清理核心模組並啟動虛擬機：

bash 
# 1. 切換至虛擬機目錄
cd ~/ot/vm

# 2. 移除衝突的 Intel KVM 核心模組（需輸入密碼 user@1234）
sudo modprobe -r kvm_intel

# 3. 啟動 Vagrant 虛擬機
vagrant up
  • Linux 主機 IP：192.168.1.33
  • 虛擬機啟動後 IP：192.168.1.32

第二階段：配置本機網路 (Windows PowerShell)

請以系統管理員身分開啟 PowerShell 並執行：

powershell 
# 1. 查詢目前的網路卡清單與名稱
Get-NetAdapter

# 2. 將指定網卡設定為靜態 IP
New-NetIPAddress -InterfaceAlias "Ethernet 2" -IPAddress "192.168.1.55" -PrefixLength 24
  • 本機設定 IP：192.168.1.55

第三階段：連線測試與 SSH 登入 (Windows PowerShell)

確認網路暢通後，直接透過 SSH 遠端登入虛擬機：

powershell 
# 1. 測試網路是否能正常連向虛擬機
ping 192.168.1.32

# 2. 使用 SSH 連線至虛擬機（執行後請輸入密碼：ubuntu）
ssh ubuntu@192.168.1.32

第四階段：還原本機網路設定 (Rollback)

實驗或工作完成（從 SSH 登出）後，將本機網路卡還原為自動取得 IP 與 DNS：

powershell 
# 1. 再次確認網卡狀態
Get-NetAdapter

# 2. 啟用 DHCP 以自動取得 IP 地址
Set-NetIPInterface -InterfaceAlias "Ethernet 2" -Dhcp Enabled

# 3. 重設 DNS 為自動取得
Set-DnsClientServerAddress -InterfaceAlias "Ethernet 2" -ResetServerAddresses

# 4. 確認是否成功取得新的 IPv4 地址
Get-NetIPAddress -InterfaceAlias "Ethernet 2" -AddressFamily IPv4
若遇到連線不通、虛擬機卡死等異常，請參考 Delta 環境重啟步驟。

環境異常完整重啟步驟 (Reset Procedure)

當遇到連線不通、虛擬機卡死或其他無法預期的網路問題時，請依照下列順序進行「軟硬體完整重啟」：

1. 關閉軟體與虛擬機 (Linux Host)

在 Linux 環境下先將虛擬機優雅關閉，避免資料損毀。

bash 
cd ~/ot/vm
# 停止 Vagrant 虛擬機
vagrant halt

2. 硬體設備斷電關機

依照依賴順序關閉硬體：

  • 步驟 A：關閉實體伺服器主機（箱子關機／vm halt）。
  • 步驟 B：關閉網路交換器（Switch 關機）。

3. 硬體設備依序重啟 (重開機)

為了確保網路派發與硬體偵測正常，請務必依照以下順序開機，並在步驟間稍作等待（約 1～2 分鐘）：

  • 步驟 A：先開啟網路交換器 (Switch)，等待燈號恢復正常。
  • 步驟 B：再開啟實體伺服器主機 (箱子重開)。

4. 重新啟動虛擬機環境

當實體主機與 Switch 都就緒後，重新執行初始化與開機指令：

bash 
cd ~/ot/vm
sudo modprobe -r kvm_intel
vagrant up
環境重啟完成後，即可回到 虛擬機操作指南的第二階段 重新設定本機網路並測試連線。
