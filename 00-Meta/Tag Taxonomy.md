# Tag Taxonomy

Standard tags for this vault. Use Obsidian tag pane to browse.

## Project

- `#project/malcolm-bec` — Malcolm BEC threat hunting project

## Tool

- `#tool/obsidian` — Obsidian-specific notes
- `#tool/malcolm` — Malcolm platform
- `#tool/opensearch` — OpenSearch queries

## Type

- `#type/howto` — step-by-step guides
- `#type/reference` — reference material
- `#type/hub` — MOC hub pages
- `#type/daily` — daily notes

## Language

- `#lang/en` — primarily English
- `#lang/zh` — primarily Traditional Chinese

## Status

- `#status/draft` — work in progress
- `#status/published` — finalized
- `#archived` — superseded or merged duplicates

## Domain (use in frontmatter `tags` array)

`malcolm`, `nsm`, `opensearch`, `threat-hunting`, `dfir`, `mitre`, `ai`, `agents`, `claude`, `cursor`, `dev`, `git`, `python`, `moc`, `meta`, `stack`, `workflow`, `obsidian`, `uncategorized`

## File naming

- Topic notes: `YYYY-MM-DD-slug.md` (e.g. `2026-05-27-malcolm-orchestration.md`)
- Daily notes: `YYYY-MM-DD.md` in `Uncategorized/daily/`
- Hub pages: no date prefix (`Home.md`, `MOC - Malcolm & NSM.md`)
- `created` in frontmatter must match the date in the filename
