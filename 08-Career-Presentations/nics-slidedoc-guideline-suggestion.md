# 大方向
- 方向可能是**SlideDoc（文件型簡報）** 或 **Read-deck（閱讀型簡報）**，文件能自己說話，而不是演講型獎報，作後演講人後的背景螢幕
- 字多詳細、提供技術細節、同時顧慮他人能看懂
- 描述背景、遇到什麼困難解決什麼問題、工作上做出什麼貢獻，帶來什麼效益、價值，before/after
- 資訊層級化」與「模組化設計」：透過分欄卡片、粗體標示核心結論、條列視覺化與一致的排版架構，就能讓高密度文字依然保持極高的可讀性與專業感。
- 公家單位用字遣詞:盡量用'之'代替'的'，使用類似'因應'、'以利'、'完成'、'發布'等
- 將**關鍵數字、特定法規名稱、最終結論**進行粗體標示，確保讀者 3 秒內抓到重點
# 公務用語與句型替換對照表

公務單位講求**精準、客觀、具動詞導向**。將口語或一般商業用語轉換為公務體系習慣之字詞，能顯著提升報告之專業度：

|**類別**|**常用/口語表達**|**建議替換之公務用語**|**實戰語句範例**|
|---|---|---|---|
|**連詞/介詞**|的|**之**|系統**之**效能評估、業務**之**執行進度|
|**動機/目的**|為了做... / 因為...|**因應... / 以利...**|**因應**使用者暴增，重構模組**以利**後續擴充|
|**執行/動作**|做完... / 發布了...|**完成... / 發布... / 辦理...**|**完成**第三階段測試，並於 10 月**發布**上線|
|**評估/分析**|看了之後覺得...|**研擬... / 綜析... / 經評估...**|**綜析**歷年數據，**研擬**妥適之因應方案|
|**成果/價值**|帶來好處 / 變快了|**展現效益 / 提升運作綜效**|**展現**跨系統整合之效益，縮短流程時間|

# 提升 Read-deck 可讀性之 key 技巧

1. **粗體標示關鍵數據**：閱讀型簡報的讀者會採取「掃描式」閱讀。請將**關鍵數字、特定法規名稱、最終結論**進行粗體標示，確保讀者 3 秒內抓到重點。
    
2. **善用狀態標籤（Status Tags）**：於卡片右上角或標題前加上標籤，如 `[已完成]`、`[列管中]`、`[預期效益]`，建立清晰之閱讀索引。
    
3. **一致的排版結構**：全份簡報每一頁的「卡片配置」應保持一致，例如一律採用「背景 $\rightarrow$ 做法 $\rightarrow$ 效益」的三欄架構，降低評委的視覺閱讀認知負荷。
