## 🛠️ 還有哪些開發者必裝的「神級標配」外掛？

除了 GitLens，以下這幾款外掛在開發圈的普及率極高，能大幅提升你的開發體驗：

### 1. Git Graph（看分支樹的神器）

- **流派：** Git 視覺化管理。
    
- **為什麼標配：** 雖然 GitLens 也有內建線圖，但 **Git Graph** 做得更純粹、更漂亮。它會用非常繽紛的捷運路線圖，畫出你專案中所有 Branch、Commit、Merge 的交錯狀況。你甚至可以直接在線圖上點右鍵進行 Checkout、Merge、Rebase，操作直覺到不行。
    

### 2. Error Lens（把錯誤頂在臉上）

- **流派：** 程式碼除錯。
    
- **為什麼標配：** 它的邏輯跟 GitLens 很像！VS Code 內建的錯誤只會在程式碼下面畫紅蚯蚓，你得把滑鼠移過去才知道錯什麼。**Error Lens** 直接把語法錯誤、Warning 的訊息**用亮色底字直接顯示在該行的尾端**。寫錯字當下立刻看到原因，省去無數個「滑鼠移過去看錯誤訊息」的零碎時間。
    

### 3. Prettier - Code formatter（程式碼潔癖救星）

- **流派：** 代碼格式化。
    
- **為什麼標配：** 不管你寫什麼語言，大家都討厭排版混亂的 Code。裝了 Prettier 並設定「存檔時自動排版（Format on Save）」，你亂塞的空格、縮排，只要按下 `Ctrl + S`（或 `Cmd + S`），0.1 秒內自動幫你對齊排好，強烈建議專案都要有一套。
    

### 4. Todo Tree（抓出程式碼裡的備忘錄）

- **流派：** 工作效率。
    
- **為什麼標配：** 我們常常會在程式碼裡寫 `// TODO: 這裡以後要重構` 或者 `// FIXME: 有 Bug 待修`。時間久了，這些註解就會散落在專案各個角落。**Todo Tree** 會自動搜集整個專案裡所有的 `TODO`、`FIXME` 標籤，並在左側側邊欄整理成一棵樹狀圖，讓你知道還有哪些坑還沒填。
    

你目前在開發時，最常遇到哪種讓你覺得「有點手忙腳亂」的場景呢？（例如：常常忘記自己改了什麼、找 Bug 找很久、還是排版很麻煩？）說不定有更對症下藥的外掛可以推薦給你！
