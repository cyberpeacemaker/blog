很遺憾，目前 VS Code **沒辦法**直接分開設定一般文字行與空白行的行高。

### 為什麼不行？

VS Code 的編輯器核心（Monaco Editor）在設計上為了極致的效能與流暢的捲動體驗，預設所有的行高（Line Height）都必須是**完全相同且固定的**。因此，只要你設定了 `"editor.lineHeight": 20`，不論該行有字還是完全空白，高度一律都會是相同的像素。

### 這是一個非常熱門的需求！

你絕對不是唯一希望有這個功能的人。在 Visual Studio（非 VS Code）中，微軟官方有一款著名的擴充套件叫作 **Shrink Empty Lines**（語法行壓縮），它能自動把不含任何字元的空白行高度垂直縮小 25%，在有限的螢幕空間裡呈現更多代碼。

而在 VS Code 的 GitHub 社群上，「縮小空白行高度」也是一個長年排在前段班的許願池功能：

- **官方討論串**：[GitHub Issue #66468 - Shrink empty lines](https://github.com/microsoft/vscode/issues/66468)
    
- **目前狀態**：雖然官方已將其移入 Backlog（待辦清單），但因為這涉及底層渲染引擎是否能支援「變動行高（Variable Line Heights）」（Issue #147067），目前依然處於開發與討論階段。
    

### 目前推薦的折衷替代方案

在官方尚未支援「分開設定」前，你可以透過以下幾種設定技巧，來改善 Markdown 檔案的閱讀配比：

#### 1. 微調 `fontSize` 與 `lineHeight` 的比例

你目前的設定是 `fontSize: 16` 搭配 `lineHeight: 20`（相當於行高只比字型多 4px，其實稍微偏擠）。

如果你希望文章有充足的呼吸感，但又不想讓空白行看起來太過空曠，建議將行高改為**倍數比例**：

JSON

```
"[markdown]": {
    "editor.fontSize": 16,
    "editor.lineHeight": 1.5 // 設為小於 8 的數字時，VS Code 會自動以「字型大小 × 倍數」計算
}
```

> **💡 實測小提示：** 使用 `1.4` 或 `1.5` 倍的行高，可以讓段落文字之間保持舒適的空隙，同時空白行的寬度也會隨之維持在和諧的比例。

#### 2. 善用「大綱折疊」功能

撰寫長篇 Markdown 時，若覺得空白行與標題太多導致畫面很散，可以直接在編輯器中點擊標題左側的 `v` 箭頭，將不需觀看的章節暫時「摺疊（Fold）」起來，這能大幅減少垂直空間的浪費。

#### 3. 利用 Markdown 格式化工具控制空行

有時空白行看起來太空，是因為不小心按了連續兩次以上的 Enter。你可以安裝像是 `Markdown All in One` 的擴充套件，並設定在存檔時自動將「連續多個空白行」格式化壓縮為「單一空白行」，維持排版的緊湊度。
