## Yes, You Can Alter It

By default, Obsidian hides file types it doesn't natively support (such as `.js`, `.py`, `.sh`, or `.bat`) to keep your note vault clean. However, you can easily change this behavior using a built-in setting.

### How to Reveal Your Script Files

Follow these quick steps to make your scripts visible in the file explorer:

1. Open **Settings** (click the gear icon in the bottom-left corner or press `Ctrl + ,` on Windows/Linux or `Cmd + ,` on Mac).
    
2. Navigate to the **Files and links** tab on the left sidebar.
    
3. Scroll down and locate the option called **Show all file types** (in some versions, this is labeled **Detect all file extensions**).
    
4. **Toggle it ON**.
    

Once enabled, your `scripts` folder and all of its contents will immediately appear in your File Explorer and become searchable via the Quick Switcher.

### 💡 Pro-Tip: Managing Code Files Inside Obsidian

While turning on this setting allows you to see and link to your script files, Obsidian treats unsupported formats like standard attachments by default. If you want to seamlessly work with them, here are your best options:

> **The Quick Fix:** You can right-click any script file in your Obsidian file explorer and select **Open in default app** to edit it instantly in VS Code, Notepad++, or your preferred code editor.

If you want to view or edit the code directly _inside_ Obsidian with proper formatting, head to **Settings** > **Community plugins** (turn off Safe Mode if prompted) and browse for these helpful tools:

- **Custom File Extensions:** This lets you tell Obsidian to treat specific extensions (like `.py` or `.js`) as plain text so you can read and write in them natively.
    
- **Code Editor:** This plugin replaces the default plain-text view for code files, adding robust syntax highlighting and developer-friendly shortcuts directly inside your vault.
