In VS Code, the hotkey depends on whether you want to toggle the preview in the **same tab** or open it **side-by-side**.

Here are the default shortcuts for Markdown files:

### Toggle Preview (In the Same Tab)

Switches your current editor view directly between the code and the preview.

- **Windows / Linux:** `Ctrl` + `Shift` + `V`
    
- **macOS:** `Cmd` + `Shift` + `V`
    

### Open Preview to the Side

Keeps your code open on one side and opens a live preview right next to it.

- **Windows / Linux:** `Ctrl` + `K` then `V` _(Press Ctrl+K, release, then press V)_
    
- **macOS:** `Cmd` + `K` then `V` _(Press Cmd+K, release, then press V)_
    

> 💡 **Tip:** If you ever want to change these, open the Command Palette (`Ctrl/Cmd` + `Shift` + `P`), type **"Preferences: Open Keyboard Shortcuts"**, and search for `Markdown: Open Preview`.
