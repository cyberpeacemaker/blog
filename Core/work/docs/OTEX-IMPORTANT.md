# 需長官審核

1. 寄信送審任何簡報時，記得以PPTX形式寄送，不需要轉為PDF格式    
2. 寄信審核時，收件人填經理，副本填總監，不會兩人同時皆為收件人  

# 撰寫報告

1. 盡量使用民國(114)，而非西元(2025)    
2. 連續兩張圖，請使用【圖表間格用】格式，將兩張圖表隔開    
3. 每一張圖皆要有對應的交互參照    
4. 「的」盡量改用「之」    
5. 使用GPT產製的文字時，請務必將中英文間之多餘空白給一併移除    
6. 出國期間包含來回飛機的時間    
7. 有關院內檔案名稱之命名方式，請依「簡報名稱v0.1_1140930.docx」格式    
8. 長官最終核定版為v1.0，故審核前之版本皆為v0.X  

# 外部單位參考會議記錄

1. 同仁撰寫之會議紀錄審核完畢後要寄送給外部單位參考時，請記得要將追蹤修訂移除，並轉為PDF形式提供  

# 國內出差

出差前：
1. 國內出差旅費申請單(電子)
2. 有連續住宿需求，請在住宿說明統一補上「因出差地偏遠且攜帶檢測設備(有保管與定點置放需求)，故住宿須連續性不可中斷。」
3. 已簽核之文件(電子)    
4. 預支單(電子)    

出差後：
1. 支出憑證黏存單(結報核銷)    
2. 國內出差旅費申請單(紙本)    
3. 國內出差旅費申請單中之所有附件(紙本)    
4. 國內出差旅費結報單(紙本)    
5. 預支單(紙本)

# 國外受訓

出差前：
1. 國外出差旅費申請單(電子)    
2. 旅行社報價單(電子)

出差後：
1. 支出憑證黏存單(結報核銷)    
2. 國外出差旅費申請單(紙本)    
3. 國外出差旅費申請單中之所有附件(紙本)
