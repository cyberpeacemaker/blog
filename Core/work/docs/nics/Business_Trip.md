	- 收據在空白處簽名
	- 黏存單簽名簽在**經辦單位**格子上方處(簽名+日期8碼)
	- 費用是總經額(收據+雜費等)
- google日曆可以列印

# 耳提面命

# 國內出差

出差前：

1. 國內出差旅費申請單(電子)    

2. 有連續住宿需求，請在住宿說明統一補上「因出差地偏遠且攜帶檢測設備(有保管與定點置放需求)，故住宿須連續性不可中斷。」    

3. 已簽核之文件(電子)
    
4. 預支單(電子)
    

出差後：

1. 支出憑證黏存單(結報核銷)
    
2. 國內出差旅費申請單(紙本)
    
3. 國內出差旅費申請單中之所有附件(紙本)
    
4. 國內出差旅費結報單(紙本)
    
5. 預支單(紙本)
    

  

# 國外受訓

出差前：

1. 國外出差旅費申請單(電子)
    
2. 旅行社報價單(電子)
    
3. 課程說明與費用之截圖(電子)
    
4. 已簽核之文件(電子)
    
5. 繼續服務保證書(紙本)

- (美金匯率)
- 美國ESTA辦理
- 護照簽證
    

出差後：

1. 支出憑證黏存單(結報核銷)
    
2. 國外出差旅費申請單(紙本)
    
3. 國外出差旅費申請單中之所有附件(紙本)
    
4. 國外出差旅費結報單(紙本)
    
5. 臺灣銀行牌告匯率(紙本)
