 有關近期組內工程師於執行檢測作業時，檢測工具觸發本院之端點防護軟體(賽門鐵克)告警，我評估了一下，決定說有需要的工程師們可以上「EFI-業務用設備免查驗需求申請單」申請免查驗，申請事由請填寫：「本組因辦理關鍵基礎設施資安防護檢測作業，需使用筆記型電腦執行威脅狩獵、端點鑑識、惡意程式分析及事件調查等工作，作業過程須存取受測主機之鑑識資料、惡意程式樣本及相關分析工具，容易觸發防毒軟體、端點防護機制或其他安全管控措施，影響檢測作業完整性與分析結果，爰申請辦理業務用資訊設備免查驗，以利檢測、鑑識分析及事件調查等作業順利執行，確保資安防護檢測工作品質與效率。」，以上說明，謝謝
